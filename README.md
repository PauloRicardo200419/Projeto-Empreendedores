## 📌 Sobre o Projeto

O **HospedaFácil** é uma plataforma de apoio à comunicação e à experiência de hóspedes voltada para pequenos anfitriões de hospedagens por temporada (Airbnb, Booking, casas de praia, serra e urbanas).

### Principais Funcionalidades da Landing Page:
1. **O Problema vs. A Solução**: Baseado no Business Model Canvas e diagnóstico acadêmico.
2. **Guia Digital Interativo (Simulador de Smartphone)**: Protótipo navegável com abas reais de Wi-Fi (com botão copiar senha e toast), como chegar, regras da casa, uso de aparelhos e dicas locais.
3. **Calculadora de Economia do Anfitrião**: Sliders dinâmicos estimando horas poupadas e mensagens repetitivas evitadas por mês.
4. **Pesquisa de Mercado e Validação de Interesse**: Questionário interativo com lógica de ramificação condicional (*Branching Survey*):
   - Triagem: Já foi hóspede? / Já foi anfitrião?
   - Trilha exclusiva do Hóspede (dificuldade de informações, dados mais procurados, uso do guia);
   - Trilha exclusiva do Anfitrião (modelo de gestão, dores recorrentes, redução de mensagens, intenção de uso);
   - Trilha combinada para quem vivenciou ambos os lados;
   - Coleta de leads para beta testing e dados estatísticos consolidados.
5. **Planos & Modelo de Negócio**: Gratuito (degustação 1 imóvel), Anfitrião Pro e Multióveis.
6. **Apresentação Acadêmica & FAQ**: Identificação dos alunos do Mackenzie e dúvidas frequentes.

## 🚀 Como Executar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador web moderno:
- No Windows: Dê um duplo-clique no arquivo `index.html` ou clique com o botão direito e escolha "Abrir com Google Chrome / Microsoft Edge / Firefox".
- Ou utilizando uma extensão como o *Live Server* no VS Code / editor de código.
